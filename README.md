# FocusTodoDesktop 2.0

四象限任务管理 + 番茄钟桌面应用，基于 Electron 构建。

个人用的效率工具，融合 **Animal Island 设计系统**（动物森友会风格 UI）与番茄工作法，让任务管理变得轻松有趣。

## ✨ 功能

### 📋 任务管理
- **任务堆**：未分类任务的暂存区，支持按 Tag 筛选
- **普通委托 / 通缉讨伐**：两栏看板（普通任务 & 紧急任务），支持拖拽分类与回拖
- **日常任务**：可设置每周频次（1-7 次/周），超额完成有彩虹渐变特效
- **Tag 系统**：8 种颜色标签，支持筛选、管理，分类统计

### 🍅 番茄钟
- **25 分钟专注**：四阶段时间轴（回顾→工作→工作→记录）
- **正/倒计时切换**：点击时间数字切换显示模式
- **加时机制**：专注结束不强制停止，进入加时，手动完成才计入休息
- **休息倒计时**：专注完成后 5 分钟休息倒计时
- **专注窗口**：独立置顶悬浮窗（类似番茄钟 mini 模式）
- **任务绑定**：可为每轮番茄钟绑定具体任务，自动完成番茄计数
- **分类统计**：按 Tag 分类统计专注时间，饼图展示

### 📊 总结中心
- **今日/本周/本月/本年** 时间范围切换
- **完成任务统计** + **专注分钟统计**
- **活动分类柱状图**：按 Tag 统计任务和活动数量
- **番茄钟分类饼图**：按分类统计专注时间分布
- **活动记录**：手动添加活动日志，带 Tag 标注

### 🎨 UI 设计
- **Animal Island 风格**：异形圆角、胶囊按钮、立体阴影、手绘风格
- **配色系统**：青绿色主调（`#19c8b9`），暖色卡背景
- **Noto Sans SC + Nunito** 字体组合
- **三栏可拖拽布局**：左侧（任务堆+番茄钟）、中间（看板）、右侧（统计）

### 🧩 其他
- **系统托盘**：最小化到托盘，双击恢复
- **桌面通知**：番茄钟阶段提示
- **音效反馈**：Web Audio API 合成的提示音与庆祝音效
- **每日结算**：日常任务凌晨 4 点自动重置
- **数据持久化**：JSON 文件存储所有数据

## 🚀 开发

### 前置条件
- Node.js >= 18
- Electron

### 安装与运行

```bash
# 安装 Electron
npm install electron --save-dev

# 启动应用
npx electron .
```

### 项目结构

```
FocusTodoDesktop/
├── main.js              # Electron 主进程（窗口管理、IPC、托盘）
├── preload.js           # 预加载脚本（contextBridge API）
├── package.json         # 项目配置
└── renderer/
    ├── index.html       # 主窗口 UI
    ├── app.js           # 主窗口逻辑（任务管理 + 番茄钟）
    ├── animal-island.css # 全局样式
    ├── focus.html       # 专注模式悬浮窗
    ├── pomodoro.html    # 独立番茄钟窗口
    ├── pomodoro.js      # 独立番茄钟逻辑
    └── files/           # 静态资源（字体、图标、SVG）
```

## 🛠 技术栈

- **Electron**：桌面框架
- **Vanilla JS**：零依赖，纯原生 JavaScript
- **Web Audio API**：音效合成
- **CSS Custom Properties**：设计 Token 系统
- **HTML5 Drag & Drop**：任务拖拽排序
- **Canvas API**：统计饼图
